# 🍽️ FoodShot AI - Instagram グルメ投稿自動デザイン化ツール

**素の食べ物写真 → バズるInstagram投稿に自動変換**

飲食グルメをInstagramで「バズらせるための」デザイン・ハッシュタグ・キャプション自動生成ツール。20-50代向けのバズ投稿パターン1000件レベルの分析から開発。

## ✨ 特徴

- **11種類のテンプレート** - ラーメン・スイーツ・寿司・イタリアンなど業種別に最適化
- **年齢層別CTA自動生成** - 20代・30代・40-50代で異なる「行動喚起」を自動選択
- **15個のハッシュタグ自動生成** - ビッグワード（2個）+ ミドルワード（3個）+ スモールワード（10個）の黄金構成
- **食べ物種別自動判定** - 画像の色分析で「何の食べ物か」を推測→テンプレート自動選択
- **メタデータ一括出力** - キャプション・ハッシュタグ・推奨投稿時間がJSON形式で即コピペ可能

## 🚀 クイックスタート

### インストール

```bash
cd instagram-gourmet-auto
pip install -r requirements.txt
```

### 基本的な使い方

```bash
python main.py <画像パス> --shop "店名" --menu "メニュー名" --price "¥価格"
```

### 例

```bash
# ラーメン投稿を生成（30-40代向け）
python main.py my_ramen.jpg --shop "〇〇ラーメン" --menu "豚骨ラーメン" --price "¥1,200" --age middle

# スイーツ投稿を生成（20-30代向け）
python main.py my_cake.png --shop "〇〇カフェ" --menu "パンケーキ" --price "¥1,500" --age young --keyword sweets

# 寿司投稿を生成（40-50代向け + 地域指定）
python main.py my_sushi.jpg --shop "〇〇寿司" --menu "握り盛り" --price "¥5,000" --age senior --keyword sushi_petrole --location "銀座"
```

## 📋 パラメータ説明

### オプション引数
| 引数 | 説明 | デフォルト | 例 |
|-----|------|---------|-----|
| `--shop` | 店舗名 | 必須 | "〇〇ラーメン" |
| `--menu` | メニュー名 | 必須 | "豚骨ラーメン" |
| `--price` | 価格 | "¥1,200" | "¥1,500" |
| `--keyword` | 食べ物キーワード（自動判定の場合は省略） | - | "ramen_warm", "sweets_white", "sushi_petrole" |
| `--age` | ターゲット年齢層 | "middle" | young/middle/senior |
| `--location` | 地域名（ハッシュタグに追加） | - | "渋谷", "銀座" |

## 📊 出力ファイル

実行後、`output/` フォルダに以下が生成されます：

### 1. Instagram投稿画像
ファイル名: `instagram_<店名>_<メニュー名>.png`

**仕様:**
- サイズ: 1080×1350px（Instagram フィード推奨サイズ）
- 背景色: テンプレートに応じて自動選択
- テキスト: 店名（上部）+ メニュー名（中央）+ 価格（右下）+ 「限定」バッジ（右上）
- フィルタ: 食べ物タイプに応じて自動適用（暖色/冷色など）

### 2. メタデータJSON
ファイル名: `metadata_<店名>_<メニュー名>.json`

**含まれる情報:**
```json
{
  "shop_name": "〇〇ラーメン",
  "menu_name": "豚骨ラーメン",
  "caption": "推奨キャプション（年齢層別CTA付き）",
  "hashtags": ["#ラーメン", "#グルメスポット", ...],
  "hashtags_str": "ハッシュタグを全部つなげたバージョン",
  "recommended_time": "11:30",  // ランチピーク時
  "age_group": "middle",
  "cta_options": ["複数の推奨CTA案"]
}
```

## 💡 バズるフィード投稿の5つのポイント

このツールが実装している、1000件分析から導出された「バズポイント」：

1. **カラーパレット** - 食べ物に合わせた背景色で「自然で上品」に見える
2. **シズル感** - 湯気・伸びるチーズ・断面を強調する位置取り
3. **テキスト配置** - 視線誘導が自然な位置に店名・メニュー・価格を配置
4. **年齢層別CTA** - 20代は「友達に送ったい」、40代は「レシピ知りたい」
5. **ハッシュタグ戦略** - ビッグワード（検索）+ ミドルワード（カテゴリ）+ スモールワード（詳細）の3層

## 🔧 カスタマイズ

### テンプレート追加方法

`templates.py` に新しいテンプレートを追加：

```python
TEMPLATES["my_template"] = {
    "name": "テンプレート名",
    "bg_color": (255, 255, 255),  # RGB
    "text_color": (0, 0, 0),       # RGB
    "accent_color": (212, 175, 55), # RGB
    "food_types": ["食べ物1", "食べ物2"],
    "target_age": "20-50代",
    "font_style": "serif",  # serif or gothic
    "filter_type": "warm_orange",  # フィルタタイプ
}
```

### ハッシュタグカスタマイズ

`templates.py` の `HASHTAGS` セクション：

```python
HASHTAGS["my_template"] = {
    "big": ["#大きいハッシュタグ1", "#大きいハッシュタグ2"],
    "mid": ["#中くらいハッシュタグ", ...],
    "small": ["#詳細ハッシュタグ", ...],
}
```

## 🛠️ トラブルシューティング

### 画像がテンプレート選択できない
→ `--keyword` パラメータで明示的にテンプレート指定してください

```bash
python main.py image.jpg --shop "店名" --menu "メニュー" --keyword "sweets_white"
```

### フォントが見つからないエラー
→ Windows の `C:\Windows\Fonts\meiryo.ttc` を使用しているため、他のOSではフォント指定を修正してください

### 出力ファイルが文字化けしている
→ JSON出力は `ensure_ascii=False` で対応済み。ファイルをUTF-8で開いてください

## 📞 よくある質問

**Q: リール動画にも対応してますか？**
A: 現在はフィード投稿（静止画）のみ対応。リール動画化は次フェーズで実装予定。

**Q: 複数の食べ物が写っている場合は？**
A: `--keyword` で主要な食べ物を指定すれば対応します。自動判定は最も色が強い要素を選びます。

**Q: 生成された投稿をすぐInstagramに投稿できますか？**
A: 手動投稿のみ対応。Instagram Graph API統合（自動投稿）は開発予定。

**Q: 背景を別の色に変えたい場合は？**
A: 出力画像をCanvaで編集するか、テンプレートをカスタマイズして使用してください。
